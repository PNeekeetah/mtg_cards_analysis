# MTG Analysis App

This app was built for the purpose of sorting my collection. It's a way for me to slice and dice my info.

## Package management

This project uses poetry. Run the following to create a virtual environment:

```
curl -sSL https://install.python-poetry.org | python -
poetry install
```

You can then run `mtg_collection_jupyter.ipynb` once you've selected your ipython kernel.
